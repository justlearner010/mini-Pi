# mini-Pi V1 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Build a public, Node 22+ TypeScript terminal Agent that explores a TS/JS project through three read-only tools and OpenAI-compatible Tool Calling.

**Architecture:** `tool.ts` provides safe deterministic facts, `llm.ts` translates mini-Pi messages to Chat Completions, `agent.ts` owns the stateful sequential loop, and `cli.ts` composes optional `tui.ts`. Core source stays in five files and under 1000 total lines.

**Tech Stack:** Node 22, TypeScript, OpenAI SDK, TypeScript Compiler API, `@inquirer/select`, Node `node:test`, `tsx`.
