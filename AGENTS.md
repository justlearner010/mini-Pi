# Contribution Workflow

For every new feature, follow this workflow before merging code into `main`:

1. Discuss the feature and write an approved specification.
2. Open a GitHub Issue for the approved scope.
3. Implement the Issue on a dedicated branch.
4. Open a pull request with tests and verification results.
5. Wait for the repository owner to review the pull request.
6. Merge only after that review is approved.

Do not bypass the Issue, pull-request, or owner-review steps for new features.
